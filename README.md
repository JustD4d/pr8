# Автономный программный комплекс электронной цифровой подписи (ЭЦП) на базе эллиптических кривых

Данный проект представляет собой программную реализацию асимметричной схемы электронной цифровой подписи (ЭЦП), функционирующей на основе группы точек эллиптической кривой в форме Вейерштрасса над конечным полем вычетов по простому модулю. 

### Ключевая особенность проекта
**Полная автономность (Zero-Dependency).** Все криптографические примитивы, включая пошаговое раундовое сжатие блоков данных (хэширование), расширенный алгоритм Евклида для поиска мультипликативно обратного элемента, а также операции сложения и кратного умножения точек на кривой, реализованы с нуля встроенными средствами языка Python без использования сторонних специализированных библиотек (таких как cryptography, pycryptodome или hashlib).

## 2. Подробное математическое описание и алгоритмы

Криптосистема оперирует числами разрядностью **512 бит**. Базовые параметры системы жестко фиксированы и задают структуру конечного поля и саму эллиптическую кривую.

### 2.1 Параметры кривой (Криптографический контекст)
* **Модуль поля ($P_{mod}$):** Большое простое число, определяющее размерность конечного поля вычетов.
* **Коэффициенты уравнения ($A$, $B$):** Задают геометрию кривой $y^2 = x^3 + Ax + B \pmod p$. В данной реализации $A = 7$.
* **Порядок группы ($Q_{order}$):** Простой порядок подгруппы, генерируемой базовой точкой.
* **Базовая (генераторная) точка $P = (X, Y)$:** Точка на кривой, многократное умножение которой формирует пространство ключей.

### 2.2 Групповые операции на эллиптической кривой
Арифметика ЭЦП строится на трех базовых операциях над точками кривой:

1. **Мультипликативное обращение (modinv):** Вычисляется с помощью расширенного алгоритма Евклида.

2. **Сложение точек:** Учитывает уравнение секущей (для разных точек) и уравнение касательной (для удвоения точки).
   * Если точки различны ($P \neq Q$), вычисляется наклон секущей:
$$\lambda = \frac{y_2 - y_1}{x_2 - x_1} \pmod p$$
   * Если точки совпадают ($P = Q$), вычисляется наклон касательной к кривой:
$$\lambda = \frac{3x_1^2 + A}{2y_1} \pmod p$$
   * Координаты результирующей точки $C(x_3, y_3)$:
$$x_3 = \lambda^2 - x_1 - x_2 \pmod p$$
$$y_3 = \lambda(x_1 - x_3) - y_1 \pmod p$$

3. **Скалярное умножение точек:** Выполняется за логарифмическое время с помощью алгоритма «удвоения-и-сложения» (double-and-add).

### 2.3 Алгоритм хэширования
Перед формированием подписи исходный файл любого объема должен быть сжат в фиксированный 512-битный дайджест (хэш-код).
* Входные данные разбиваются на блоки по **64 байта (512 бит)**.
* Каждый блок складывается поразрядно по модулю 2 (XOR) со значением текущего внутреннего состояния.
* Далее блок проходит **12 раундов перемешивания**, обеспечивая лавинный эффект.
* На этапе финализации к сообщению дописывается его полная битовая длина для защиты от атак типа «удлинение сообщения».

## 3. Пошаговые криптографические процедуры

### Генерация ключей
1. Случайным образом выбирается целое число $d$. Это **секретный ключ подписи**.
2. Вычисляется точка кривой $Q = dP$. Координаты образуют **открытый ключ проверки**.

### Формирование подписи
1. Вычисляется дайджест файла ($e$).
2. Выбирается случайное эфемерное число $k$.
3. Вычисляется точка кривой $C = kP$. Параметр $r = X_C \pmod Q$.
4. Вычисляется параметр $s = (rd + ke) \pmod Q$.
5. Результирующая подпись представляет собой конкатенацию байтовых представлений чисел $r$ и $s$.

### Проверка подписи
1. Извлекаются числа $r$ и $s$ из файла подписи.
2. Вычисляется дайджест файла $e$.
3. Вычисляются коэффициенты восстановления: $v = e^{-1} \pmod Q$, $z_1 = sv \pmod Q$, $z_2 = -rv \pmod Q$.
4. Вычисляется проверочная точка на кривой: $C = z_1P + z_2Q$.
5. Если $X_C \pmod Q = r$, подпись признается истинной.

## 4. Инструкция по запуску и использованию

### 4.1 Системные требования
* **Интерпретатор:** Python версии 3.10 или выше.
* **Операционная система:** Любая (Windows, Linux, macOS).

### 4.2 Клонирование и запуск
Откройте терминал вашей операционной системы и выполните команды:

    git clone https://github.com/your-username/elliptic-signature-gost.git
    cd elliptic-signature-gost
    python main.py
